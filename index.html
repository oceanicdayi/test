一、課程定位

本課程是為中小學現職教師設計的暑期地球科學課程，內容以地震學與地球物理學為主軸，同時導入 AI／Agent 工具與雲端平台，讓教師能把地震學知識轉化為可帶回學校使用的教材、互動網頁、資料分析活動與教學專題。

本課程也可作為開學後「地球物理學」課程的前導與素材庫。暑期課程偏重教師研習、動手做與教學轉化；開學後課程則可在相同素材基礎上加深理論、數學、資料分析與研究應用。

🎯

二、課程核心目標

01

建立中小學教師對地震學與地球物理學的基本理解。

02

學會使用真實地震資料進行簡單分析與教學設計。

03

練習將地震學概念轉化成中小學可理解的活動。

04

熟悉 opencode, Antigravity CLI, Hermes agent, GitHub, Hugging Face, Vercel, Google GAS/GWS 等工具。

05

透過 Google GWS 與 GAS 建立教學自動化、資料收集與成果展示流程。

06

每週完成一個可檢核的作業，落實動手做與產出。

07

安排一次野外實驗或簡易地震儀觀測活動。

08

最後產出一份可直接帶回學校課堂應用的地震教學作品。

📍 每週課程詳情

探索每週的主題細節、手把手教學實作與檢核作業標準

Week 1

課程介紹、帳號申請、軟體安裝與工作流程建立

📅 2026 / 07 / 17

🔧本週重點任務

  • 建立 Google Drive 課程資料夾與雲端工作區
  • 註冊並設定 GitHub 帳號與個人教學 repo
  • 註冊 Hugging Face 與 Vercel 雲端部署平台
  • 測試 Google Forms、Sheets、Apps Script 連動
  • 安裝 Git、VS Code、Python、Node.js、Java
  • 導覽 opencode、Antigravity CLI、Hermes agent

📝作業 1：完成個人數位學習工作區

檢核標準：

  • Google, GitHub, HF, Vercel 至少完成 3 項註冊
  • 建立帶有 README.md 的 GitHub 專案庫
  • 成功執行並截圖一段 GAS 雲端測試程式
  • Git, VS Code, Python 等核心軟體完成安裝
Week 2

地震儀、加速度、地震動與震度

📅 2026 / 07 / 24

📶本週重點任務

  • 探索地震儀硬體原理：它到底記錄了什麼資料？
  • 探討地面搖晃（地震動）的量化與物理意義
  • 分析加速度 (PGA, PGV) 與氣象署震度分級的關聯
  • 實作：使用手機感測器收集三分量震動數據
  • IRIS ground-shaking 教案之教學法與學生活動轉化

📝作業 2：完成簡易震動觀測活動

檢核標準：

  • 繳交至少一筆真實感測器震動紀錄數據
  • 於試算表呈現具備物理意義的震動分析圖表
  • 設計含有至少 3 題引導思考的學生學習單
  • 清晰說明「感覺到的搖晃」與「儀器測量」之差異
Week 3

P-S 到時差、旅行時間曲線與震央定位

📅 2026 / 07 / 31

🎯本週重點任務

  • 認識走時曲線 (Travel-Time Curve) 的生成與應用
  • 利用 P 波與 S 波到時差計算觀測站與震央的距離
  • 操作經典 IRIS 震央定位教案 (圓規畫圓交點法)
  • 利用 Python 或試算表自動化輔助繪製定位圖面

📝作業 3：完成震央定位教學範例

檢核標準：

  • 準確標示並計算出至少三個測站的 P/S 走時數據
  • 藉由走時圖表正確推估各測站的震央距
  • 畫出或產出三個距離圓圈交會定位圖面
  • 設計問題，引導學生反思「為何需要至少三個測站」
Week 4

課本精讀與真實地震波形資料分析

📅 2026 / 08 / 07

📖本週重點任務

  • 深讀經典教材 Introduction to Earthquake Seismology 第 4 章
  • 學習使用 jAmaSeis 或網路公開地震資料庫下載地震波形
  • 實際在波形圖上指認 P波、S波 及表面波等多重波相
  • 討論哪些理論深度適合中學，哪些適合作為開學延伸課程

📝作業 4：第 4 章導讀與波形小報告

檢核標準：

  • 以中學教師好懂的語彙整理出第 4 章重點導讀
  • 提供一張標記了 P/S 波與關鍵特徵的真實波形圖
  • 明確劃分「中小學簡化版」與「大學地球物理版」深度
Week 5

規模、震度、場址效應與建物反應

📅 2026 / 08 / 14

🏢本週重點任務

  • 徹底釐清學生最容易混淆的：地震規模 vs 地震震度
  • 探討盆地放大效應與場址效應 (Site Effect)
  • 探討共振現象與不同樓高結構物在地震中的反應
  • 實作：利用 Vercel 與 GitHub 建立網頁，並串接 GAS 後台

📝作業 5：地震防災互動網頁初版

檢核標準：

  • 上傳至 GitHub Pages 或 Vercel 並能公開存取
  • 網頁需有精美清晰的「規模 vs 震度」科普圖文
  • 含場址效應說明及至少 1 個可與讀者互動的測驗題
Week 6

野外實驗、成果整合與教案發表

📅 2026 / 08 / 21

🌾本週重點任務

  • 戶外實作：校園微動觀測或簡易地震儀架設操作
  • 整合前 5 週學習素材與數位工具成果
  • 套用 IRIS Teachable Moments 教學架構與 AI 潤稿輔助
  • 舉行期末教案發表會 (每人 5–7 分鐘分享)

📝作業 6：期末教學作品與發表

檢核標準：

  • 繳交含教案、學生學習單、教師指南的整合專案
  • 提供最終可用於教學的數位作品成果連結
  • 完成發表簡報並能現場闡述其學術深度與創造力
🔗

五、開學後「地球物理學」課程共用與延伸規劃

暑期課程教學與實作內容 開學後「地球物理學」進階延伸方向
Week 1 工具環境與 GitHub 流程 在大學部正式導入 GitHub 與資料分析工作流，進行科學程式與版本管理。
Week 2 地震動數據與震度感知 深入研究地震動參數，探究 PGA、PGV 物理推導與地動加速度換算震度之數值擬合。
Week 3 走時曲線與幾何震央定位 引入地球速度結構分層模型、非均勻介質射線追蹤以及反演定位演算法與誤差橢圓分析。
Week 4 第 4 章精讀與實際波相觀測 作為理論課程主軸，深入解算波動方程式、格林函數、橫波反射折射係數與複雜波相識別。
Week 5 場址效應、建物反應及網頁 導入淺層地球物理探勘、微動觀測 (HVSR 技術)、地盤放大係數及結構動力學分析。
Week 6 校園實地微動與專題整合 進行正規地震儀觀測野外實習、完整的地震資料去雜訊處理、頻譜分析與研究論文專題撰寫。

20%

包含數位工具測試、同儕討論分享、教學法思辨與互動轉化熱烈度。

課程核心理念
